# WaveLynk Conference Poster & Visual Presentation

> **Project Title:** WaveLynk: Predictive Beamforming Switching for Wi-Fi 7 and 6G Systems  
> **Authors:** Neha Abin, Sahil Shah, Yajat Parmar  
> **Affiliation:** Allen High School, Allen, TX

---

## Overview

This directory contains presentation materials, poster figures, and visual summaries prepared for IEEE conference sessions and technical showcases.

### Key Visual Highlights

1. **The Coherence Cliff Problem:** Demonstrating non-linear throughput collapse when CSI feedback delay reaches $\tau \approx 0.3 \cdot T_c$.
2. **The Conditioned Coherence Index (CCI):** The 4-parameter formulation unifying matrix condition number $\kappa(\mathbf{H})$, Bessel Doppler decay $J_0(2\pi f_D \tau)$, normalized SINR weighting, and exponential aging decay.
3. **Analytical Boundary ($\gamma = 0.6$):** The critical switching threshold derived from first principles.
4. **Hardware Validation:** Empirical 100-trial results across a 6 GHz Netgear Nighthawk Wi-Fi 7 testbed showing 41% outage reduction and 32% latency stabilization.
